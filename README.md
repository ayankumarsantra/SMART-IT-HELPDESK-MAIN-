# SMART-IT-HELPDESK-MAIN-
A C-based Smart IT Help Desk and Incident Management System with automatic ticket categorization, priority assignment, status tracking, and deletion of resolved tickets.
This project provides a simple IT help desk system where employees can create support tickets and administrators can view, search, update, and manage those tickets.
The system automatically assigns a category and priority to a ticket based on keywords entered in the problem description.
